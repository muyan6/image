# 最新云端模式与微信网页登录

## 当前行为

- 管理界面不再提供传统图片处理、旧版 CI 主动审核、biz-type 或生成模式切换。
- 旧设置文件首次升级自动切到云端异步生成和微信优先审核；内部历史处理函数仅保留兼容/回归用途。
- 原图先冻结至服务端控制的 COS 对象，再提交微信链接审核；大于 10 MB 或微信故障转腾讯云专用目录。
- 图片和文字共用“启用内容审核（图片＋文字）”开关；文字优先微信，腾讯云文字审核兜底。
- 原图、对比图、成品从任务完成起统一保留 30 天；已经删除的旧图片不会恢复。
- 旧的 24 小时清理记录会更新为新保留期限，已主动删除或失败的任务不会延长。
- 临时上传、审核副本、供应商导入缓存不是用户作品，仍按短期策略清理。
- 主动删除会先隐藏/取消任务；供应商付费提交之前退回预扣光子，提交之后取消不退款。随后立即删除本地与该任务所有私有 COS 对象；失败项持久重试。
- 并发已进入清理操作的旧签名链接、COS 删除的瞬时竞态需通过上线验收确认；开启版本控制的桶另需检查历史版本生命周期。
- 调度仅遍历处理中任务索引，不排序完整历史；保留中的作品不再因内存条数限制提前删除。
- 原图/导入信息与成品尺寸复用；最终交付仍保留对象存在性检查。
- 记录准备、原图审核、提交、供应商、导入、成品处理、成品审核和总耗时。

## 微信网页登录上线顺序

1. 发布小程序的新页面 `pages/web-login/web-login`（正式版）。
2. 后台微信 AppID/AppSecret 配置与发布小程序一致。
3. 部署后端、更新网页；网页通过 POST `/api/auth/wechat-web/start` 创建五分钟登录会话。
4. 微信扫描小程序码，进入确认页，点击“确认登录”；GET 状态接口向创建该码的浏览器发放同一微信账户会话。
5. 网页与小程序共用用户余额、作品、处罚状态；没有新访客注册。历史访客余额/作品保留，不猜测微信归属，不自动迁移。
6. 在 COS 配置浏览器 CORS：允许网页实际域名（例如 `https://image.myil.top`），PUT/GET/HEAD，允许 Content-Type 等实际使用的请求头。
7. 网页图片使用 `/api/uploads` 申请授权后直传 COS，再经 `/api/rescue/by-upload` 提交元数据；不回退到服务器 multipart 上传。

网页登录会话绑定 HttpOnly、SameSite=Strict 浏览器 Cookie；扫码页只有公开随机会话号，没有浏览器秘密。
确认必须使用已鉴权的微信账号，浏览器不能通过传入 openid 指定账户。
每个客户端地址一分钟最多创建五个登录码，过期、拒绝、重复确认、微信配置变更均有独立处理。
小程序未发布新页面时，微信生成码可能拒绝请求；页面会显示错误，不创建替代访客账户。

### HTTPS 反向代理下的登录来源

`WEB_PUBLIC_ORIGIN` 指定浏览器实际访问的站点，默认 `https://image.myil.top`。
该站点外部 HTTPS、代理到后端内部 HTTP 时，登录来源按此明确配置比较，Cookie 仍设置 Secure。
部署在该默认域名时更新后端并重启即可；其他域名在后端 `.env` 设置 `WEB_PUBLIC_ORIGIN=https://实际域名`，再重启。
值只包含协议、域名和必要端口，不含路径。其他域名、错误端口、HTTP 降级及伪造转发头不会扩大允许范围。
直接 localhost/127.0.0.1/::1 调试可使用与请求地址一致的来源。
Nginx/Caddy 应保留原 Host，正确传递 X-Forwarded-Proto；只有可信代理可设置这些头。
此修复不依赖信任任意来源的 X-Forwarded-* 头，也不设置通配符登录来源。

## 后台解封

用户管理点击“解封”，随后选择是否重置本轮处罚计数。
重置只更新计数起点，保留违规历史、原扣款和复核入口，不自动退款。
仅解封但不重置时，后续违规仍会计入原七日窗口。

## 腾讯云规则

仅配置 `audit-tencent/input/`、`audit-tencent/output/`，不配置整个桶、uploads/ 或 results/。
回调固定 `https://image.myil.top/api/callbacks/cos-audit`，完整 0–100 结果及失败事件，详细回调、HTTPS、COS 域名。
无需手工创建目录，后端 COS 内部复制对象时自然形成目录。
实际 CopyObject 自动审核触发、资源包抵扣、权限和回调送达需要在对应云账号验收。

## 供应商完成通知

现用 WorldCodes 异步接口只在本地实现中确认提交和任务查询；未取得可验证的 webhook 合约。
本次不擅自添加供应商不认识的 callback 参数，保留现有查询以确保任务完成。
取得供应商回调地址参数、通知字段、验签、重试和任务编号规则后，再接入完成通知并降低兜底查询频率。

## 生图延迟与回归检查

- 准备、付费提交以及供应商完成后的导入、成品处理等立即可执行阶段，在同一次工作线程调度中连续推进；远程生成和审核等待仍释放线程，不忙等。
- 新任务登记会唤醒调度器；供应商查询周期仍遵从后台配置，没有以重复付费提交换取速度。
- 已接受的 COS 回源先以 0.5 秒探测，再逐步退避至最多 5 秒；回源重触发次数和总等待期限保持有界。
- 前台任务状态默认每 1.5 秒查询，不再仅因云端模式或排队状态强制等待 5 秒。作品列表一次请求同步多个任务，页面隐藏后停止轮询。
- 客户端并行准备登录与公开配置、文件读取与上传授权；仅合并在途配置请求，不缓存价格或维护配置。
- 常用配置读取只复制相应配置节，保留锁和返回值隔离，避免每次生图请求都复制完整社区列表。
- 新安装的任务库与封面遵从 DATA_DIR。已有安装若任务库仍在旧 backend/data/jobs.db 且新目录尚无任务库，会沿用旧任务库，保留历史和在途任务，不隐式搬迁数据库。
- 模型、输入尺寸和内容审核保持不变。离线专项测量证明的是程序等待和 CPU 开销减少，不是供应商实际推理时间；线上比较使用任务 timings 中的 queue_ms、provider_ms、import_wait_ms、processing_ms，并按档位及供应商分组。
- 完整离线检查入口为 `python backend/tests/run_review.py`，覆盖业务、前后端联动、上传审核、付费边界及本轮延迟专项。供应商响应不明确时不自动重发付费请求，前端保留已知任务编号供继续查询。

### 后续顺序修复与连接复用

- 公告和模板 CRUD 先把候选数据原子写入，再发布内存状态；磁盘异常不再让失败请求的修改出现在后续响应或保存中。读取、迁移 I/O 异常不按损坏 JSON 重置有效内容。
- 占位封面尊重公开主图引用，独占创建新文件，不覆盖已有或共享封面；元数据提交失败时只回收本次生成的新文件。
- 小程序保留本次登录凭据以应对缓存写入失败，但主动清除或替换缓存仍使旧凭据失效。文生图只对真正提交后的不明确响应阻止重提，不把前置登录失败误判为已生成。
- 网关 JSON 与 COS 控制请求复用线程独立的 HTTP 连接池，缓存每线程最多八个来源、每来源一个空闲连接；不新增自动请求重试，不跟随重定向，不持久化响应 Cookie 或默认供应商凭据。线程退出关闭连接，退出进程时补充清理。
- 文生图配置使用局部节读取，ready 检查和网关投影复用同一份配置，保持热更新和显式空密钥语义。
- 连接复用由真实本机 HTTP/1.1 socket 计数验证，未据此承诺供应商网络或模型推理的具体提速比例。

### 网关成本与光子售价分开记录

- 模板/原片修复的光子售价仍跟随全站档位价格，不把人民币供应商成本换算成用户扣点。
- 云端任务受理时冻结所选档位的供应商人民币参考价；文生图使用自己的供应商参考价。供应商明确完成后，后台立即记录 `cost_cny` 与 `cost_estimated`，后续 COS 导入或审核失败仍保留生成参考成本。未提交、明确生成失败或结果不确定的任务不冒充已完成费用。
- 后台 `≈¥` / `≈$` 为参考估算，不是供应商实际账单；小于一分钱的人民币成本显示四位小数。历史无成本快照的记录继续显示 `—`，不会用当前价格伪造历史成本。
- 同步兼容链路也标明参考成本；云端成本快照、零成本与已有实际成本在重启恢复中保持不变。相关专项为 `test_gateway_cost_tracking.py` 与 `test_community_action_cost_display.cjs`。


### 小程序关闭文字生图入口，后端接口保留

- 后端 `/api/text-generation`、文字模型配置、鉴权和记账逻辑保持不变，供独立后端调用；照片修复、模板生成、模板文字字段和已有作品保留。
- 此调整以重新编译、上传并发布新版小程序生效；无需关闭后端文生图开关。专项为 `test_text_generation_frontend_disabled.cjs`、`test_text_generation_api_preserved.py`。
