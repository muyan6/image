# 用户模板分享

## 使用入口

- 小程序、网页「模板」提供「分享我的模板」与「我的模板」；「我的」也可进入。
- 模板库不新增用户分享/最新分类。在「全部」里可选择热度（默认）、最新、随机；随机结果在本次浏览中保持稳定，点击「换一批」才重新打乱。
- 普通分类按后台设置的顺序；收藏正常按所选排序，最近使用按自己的使用时间。
- 卡片右上角区分「官方」「用户分享」。详情显示作者，保留高清示例与正常生成价格。小程序详情可直接分享模板链接，网页可复制同款入口。

## 投稿和审核

1. 填写名称（最多20字）、介绍（60字）、提示词（4000字），上传1–3张JPEG/PNG/WebP效果封面（每张8MiB以内）。封面尺寸64–12000像素、总像素不超过4000万、宽高比1:4至4:1。
2. 选图指南可以自己填写，也可复制页面提供的AI指令，到自己常用的AI整理后核对。第一版不自动调用收费AI。指南含建议、适合、不适合、技巧；每组最多8条，每条最多60字。
3. 草稿与未审核封面只供本人、后台查看；提交公开审核时须勾选有权分享的确认。提示词不会出现在公开模板接口。
4. 后台「模板投稿」查看封面与内容，可修改文字/指南、选择已有分类或「仅全部」，然后通过、退回或下架。不新增分类、不做模板重复监测。
5. 审核通过才发布。修改已通过模板会产生新版本，旧审核版继续使用，直到新版本通过才替换；首次上架时间不因改版刷新。
6. 作者可撤回；关联账户读取同一投稿记录。服务器会检查当前发布状态、账号封禁和分享开关，不用客户端传来的作者或来源做授权。

原「模板管理」中的用户分享投影只读，请到「模板投稿」修改/下架，避免审核记录与公开模板分叉。普通用户不能提交模型、档位、价格、运行尺寸、来源、作者或热度等配置。

## 作者奖励

后台「模板投稿」可设置：

| 项目 | 默认 |
| --- | --- |
| 模板分享开关 | 开启 |
| 作者奖励开关 | 开启 |
| 每次合格奖励 | 40光子 |
| 奖励方式 | 同一使用者首次成功使用同一模板 |
| 作者每日奖励额度 | 400光子 |
| 全站每日奖励额度 | 4000光子 |

奖励仅给作者，使用者按原规则扣光子，没有额外获赠。可改成每次成功使用发放；自用（含关联账号）、免费/零扣款、失败或取消均不发奖。额度为0时不发奖，不代表无限；不足一份奖励额度时不发部分奖励。每日额度按UTC+8计算。

任务接受时冻结模板、作者、审核版本和奖励规则。成功交付后与扣款结算在同一用户数据库事务中发奖；刷新、重复回调、重启不重复发放。模板改版、奖励开关变化和退款不会重置首次使用资格。模板热度仍累计成功使用，不依赖奖励发放。

若已发奖励的任务之后退款，作者已有余额不被强扣；系统保留待冲正记录，仅从后续作者奖励抵扣。个人「我的模板」和后台详情可查看累计奖励、实际到账和待冲正金额，光子明细保留真实余额变化。删除作品或图片自然到期不是退款。

## 部署

更新后端，重新上传并发布小程序；网页文件由既有更新脚本自动构建。已有宝塔静态直出会随更新刷新公开资源。

封面通过签名PUT直接上传COS；暂存文件与审核用私有副本分开，确认后不能通过原PUT地址改写审核图片。服务器仅读取少量格式信息，不中转整张封面。网页COS CORS需允许实际网站Origin、PUT/GET/HEAD和 **Content-Type、x-cos-acl** 请求头。参考：[COS预签名上传](https://cloud.tencent.com/document/product/436/35153)。

部署前保留一致的 `users.db`、`templates.json`、`settings.json` 及清理队列备份；数据库备份应包含一致的WAL状态，或停服后备份。新增SQLite表自动建立，旧官方模板及账户余额保留。

本地 `audit` 回退材料只恢复本次源码，不撤销已发生的奖励、投稿和云端图片。已有投稿/账务后回退正式服务时，应配套核对数据备份与在途任务，不用源码回退脚本删除运行数据。

## 验收

专项：投稿权限/不可变封面/审核版本、奖励事务/别名/退款/并发、两端排序和表单、后台审核及完整生成联动。所有自动测试使用隔离合成数据、模拟COS和模型响应，不产生实际生成费用。
