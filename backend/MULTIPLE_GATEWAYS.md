# 多个中转网关

## 后台操作

- 在「供应商与提示词」添加网关、填写自定义名称，分别配置轻量/精细档位。
- 每档独立填写 Base URL、密钥、模型、POST 路径、超时和人民币参考单价。
- 标准 OpenAI 直接返回图片的接口选择「OpenAI 兼容」；返回异步任务编号的现有接口选择「云端异步」。新网关默认兼容模式，原网关保留原异步方式。
- 异步 POST 路径可单独填写；留空沿用原接口的 `/async` 形式，已经以 `/async` 结尾时不重复追加。
- 上下移动决定优先级，启停只影响新选择。名称可以修改，内部稳定编号不随名称改变。
- 至少保留一个网关，最多 20 个；全部停用时，新任务明确显示通道未就绪，不再生成本地替代结果。
- 保存统一作用于当前页；切换编辑网关保留草稿。密钥显示打码值时保存保持原值，明确清空则清空该档密钥。

## 运行与费用

- 新任务按优先顺序选择可用网关，冻结网关编号、名称、调用方式、接口、模型和参考价格；任务不保存原始密钥。
- 明确未被接收的请求可尝试后续网关；超时、网络不明、服务端不确定或已经受理的任务不自动再次提交。跨处理方式沿用同一个任务和原有光子预扣，不再次预扣。
- 已受理任务继续对应原网关；重新排序、改名、停用不会让轮询访问另一家。删除连接或变更地址/密钥后，原任务按已有核对/失败流程处理，不借用其它连接的密钥。
- 文字生图继续使用已有独立连接，不从图片网关中自动借密钥。
- 当前云端异步接口沿用原有受限 COS 图片回源规则。其它图片域名或不同异步协议需要配置与该服务一致的接入，不从返回的未知 URL 自动扩宽回源范围。
- 「今日参考成本」和「累计总参考成本」汇总已记录费用；用户退款不代表供应商费用退回。人民币和历史美元费用分别显示，不自动换汇相加。
- 成本表只有任务随机编号、供应商名称/编号、时间和费用，不保存账号、图片、提示词或密钥。新成本记录独立保留，不随作品过期或删除消失；历史没有记录的成本不按当前价格补造。

## 更新与回退

- 更新后端并重启服务；原网关连接自动保留，旧 fal/百度/本地模式不再参与新任务。
- 设置迁移前在运行数据目录保留原设置的字节级备份；失败时不发布新内存配置。
- 代码回退脚本只恢复本次代码，不改运行数据库、真实密钥或媒体。若要同时恢复旧供应商配置，应在停止受理任务后使用本地迁移备份恢复设置，再启动对应旧版本。
- 本次离线测试使用模拟网关和测试数据库，不调用真实付费生成接口。
